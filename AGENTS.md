# HisFullGlory Daily Walk

Build a compact English mobile-first PWA: Vite, React, strict TypeScript, plain CSS, lucide-react, Supabase JS, vite-plugin-pwa. Four tabs only: Today, Plans, Community, Shop. No routing or state library.

Keep journals, onboarding, completed local dates and five-day plan progress in one versioned localStorage adapter. Journals never leave the device. Use exact public-domain WEB quotations, labeled WEB. Support a polished read-only community demo when Supabase is absent.

Community uses email magic links, private own profiles, three fixed rooms, plain-text messages, prayer posts and one reaction per user/post. Enforce authorization with RLS, constraints and database cooldowns. Never use service-role credentials, expose secrets, log personal text, or add advertisements to conversations. Manual moderation uses Supabase dashboard.

Use the specified warm palette, Manrope/system fallback, max-width 480px, 44px tap targets, visible focus, and reduced-motion support. Cache only app-shell/static assets. All commerce links stay on HisFullGlory.

Run npm install and npm run build (TypeScript plus Vite). Verify storage recovery, streak idempotence, demo writes disabled, PWA output, and SQL authorization. Review the final diff for secrets and unsafe rendering. Work sequentially; no agent delegation or screenshots.

Do not add native apps, Bible APIs/readers, runtime AI, push notifications, uploads, private messages, custom rooms, presence, threads, public profiles, admin UI, CMS, payments, checkout, Shopify API, journal cloud sync, a backend, paid services or deployment. Do not edit DNS or the live Shopify store.
